# 旅行照片拼贴 · Travel Photo Collage

一个面向 AI agent 的图像创作 Skill：把一组旅行照片按同一环境或相关元素组合成超现实波普拼贴系列。保留黑白造像、建筑与真实材质，让局部原色和自然衔接的双色背景一起构成画面。

适合寺庙、石窟、古建、风景和旅行文创照片。默认输出 **3:5 竖版、无文字**；支持多图组合和已有作品优化。

## 效果与特点

- **多图组合**：把同环境的主景、细节和装饰组织在一张画面里。
- **来源可追溯**：手势、瑞兽、屋檐、云纹和壁画细节来自上传照片。
- **双色自然衔接**：色形沿岩层、衣褶、背光或屋檐延伸，避免生硬分割。
- **黑白与原色交织**：黑白主体建立层级，局部彩绘、金冠或瓦饰保留原色。
- **系列各有特色**：根据素材调整构图与色对，不用统一底色套模板。

生成式编辑可能重绘细节，本 Skill 不保证像素级抠图或文物精确复原。

## 安装

### Codex

下载仓库后，将包含 `SKILL.md`、`agents/` 和 `references/` 的整个文件夹放到：

```text
~/.codex/skills/travel-photo-collage/
```

在新的会话中使用 `$travel-photo-collage`。图像生成需要当前环境提供可用的图像生成或编辑工具；安装 Skill 本身不会安装模型服务。

### 其他支持 Skills 的 agent

将整个文件夹放入该工具支持的 Skill 目录，按其加载方式调用。工具路径与图像参考方式以目标环境为准。

### 直接在图像工具中使用

也可以阅读 [SKILL.md](SKILL.md)，按其中的素材分组、源形关系和检查规则编写提示词。

## 用法（30 秒版）

1. 上传一组旅行照片，说明地点，以及想要保留的元素。
2. 调用 Skill，让 agent 按环境与主题分组，并决定合适张数。
3. 每张选一个主锚点和一个放大细节，确定双色背景从哪个原图轮廓延伸。
4. 生成后检查脸部、手势、来源元素、文字和宽高比，再针对具体问题优化。

例如：

```text
使用 $travel-photo-collage，把这些石窟照片组合成一组拼贴。
同一洞窟或同类造像放在一起，手势和纹样使用我提供的照片。
黑白主体保留少量原色，各张使用不同的自然双色背景。
全部 3:5 竖版，不要文字。
```

优化已有作品：

```text
使用 $travel-photo-collage，优化这组拼贴。
背景太生硬，让颜色沿原图云纹、衣褶与屋檐衔接。
减少整圈厚描边，保留主体和真实手势，去掉文字。
```

## 核心规则速览

| 规则 | 画面要求 |
| --- | --- |
| 同环境组合 | 相关景物互相联系，避免混入其他地点 |
| 真实来源 | 不编造额外手掌、脸部或装饰纹样 |
| 一处尺度变化 | 优先只放大一个来源细节 |
| 自然双色 | 色形与原图轮廓穿插，不做随意几何切分 |
| 适度密度 | 主体清晰，丰富但有安静空间 |
| 无文字竖版 | 默认 3:5，交付时检查实际尺寸与字形痕迹 |

用户明确指定的比例、文字、色彩与张数优先于默认值。

## 构图示例

- 屋檐与庭院：建筑为主景，放大原图檐铃，背景沿屋檐弧线展开。
- 坐像与莲座：保留原姿态，将一片原图卷浪放大，连接背光与衣褶。
- 飞天与藻井：洞窟造像和浮雕组合，一朵原图莲花成为尺度变化。
- 旅行文创：放大实际玩偶，与同地点建筑和崖壁形成趣味对照。

更多组合关系见 [构图参考](references/compositions.md)。当前发布包不包含原始照片或作品图片。
